# Get started

The shortest way from a server with Infraternal on it to a terminal that keeps running when you close the tab.

## The first steps

1. **Create your account.** When a server starts with no owner, it prints a one-time setup code in its log. You use it to create the first account. See [First-owner setup code](/docs/reference/keys/#first-owner-setup-code).
2. **Add a machine.** The server connects to it over SSH and gives it a join token. See [Host join token](/docs/reference/keys/#host-join-token).
3. **Open a terminal.** Every terminal is a session that keeps running on its machine. See [What the multiplexer does for you](/docs/terminal/multiplexer/#what-it-does-for-you).
