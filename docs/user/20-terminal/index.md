# Terminal

Every terminal is a session that keeps running on its machine, and you arrange sessions as windows on the canvas.

## What is here

A session survives a closed tab, a lost connection and an upgrade of Infraternal, and you can open the same session from another device. The [Infraternal Multiplexer](/docs/terminal/multiplexer/) page explains how, and what Infraternal offers when your shell starts tmux or Zellij by itself.
