# Documentation

Guides for using Infraternal, written for the people who use it.

## Finding your way

The docs follow the app. Get started comes first, then a section for each part of Settings in the same order, and Reference comes last. Each section opens with a one-screen overview that lists its pages.

Each page starts with a one-sentence summary. A list of its sections stays beside the page on a wide screen, and folds into a single row under the summary on a phone. An address names the section, the page and the heading, for example `/docs/terminal/multiplexer/#how-switching-works`.

You can also search from the app. Press Cmd+K on a Mac, or Ctrl+K on Windows and Linux, and type the name of a section, a page or one of its headings. Enter opens it in the Docs view on the canvas.
