# Documentation

Guides for using Infraternal, written for the people who use it.

## Finding your way

Each guide starts with a one-sentence summary. A list of its sections stays beside the page on a wide screen, and folds into a single row under the summary on a phone.

You can also search from the app. Press Cmd+K on a Mac, or Ctrl+K on Windows and Linux, and type the name of a guide or one of its sections. Enter opens it in the Docs view on the canvas.
