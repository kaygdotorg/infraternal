fix(server): move bounded native writes out of terminal actor turns

actor and delayed independent terminal progress. Own one <=16KiB input flight
per writer with a durable-Ack window, coalesce credit/resize, and bound encoded
control to one active plus one queued <=33024-byte frame. Saturating control
pauses control admission while native terminal delivery remains readable.
Abort and join flights on replacement; retain existing transport-loss behavior
for ordinary failures. Reject unbounded spawning and socket-completion input
credit because only the shim durable cursor releases retained input.
