fix(server): wait for each writer's retained-input credit (#129)

Retaining 4 MiB previously made the next byte return false and retire the
shared host connection during replacement. Gate attachment Input against
the authoritative shim Ack before enqueueing; publish credit on every Ack
and retain the same watch through reconnection. Duplicate input uses no
additional credit. A producer bypassing the public handle receives an
explicit stream Close while sibling routes survive.

Reject increasing the memory cap, dropping unacknowledged input, and waiting
inside the shared actor: they hide the bound or stall every writer. Keep
frame-count and byte credit as independent limits. D128, D215.

credit regression failed. After repair the embedded regression suite passes
