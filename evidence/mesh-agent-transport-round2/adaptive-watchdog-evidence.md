All six windows retained 1,000 live QUIC pairs. Failed guards had no closure/error from their live connection. Failed windows retire guard tasks, so their CPU cannot be presented as the cost of 1,000 continuously healthy watchers. RSS delta includes both peers, endpoints, runtime and diagnostics; it is not per-daemon RSS or controlled allocation attribution. Production freshness state stays 208 B/path × 1,000 = 208,000 B.

The gap-diagnostic rows include one extra authenticated stats snapshot per actual guard poll and a bounded 32-bin histogram. The pure poll-diagnostic row omits that extra snapshot. Histograms describe observation-sampled authenticated frame changes, not packet timestamps. Neither raw UDP counters nor replayed/invalid packets count as freshness.

Baseline timing disproved plain watchdog starvation in those windows: per-timeout poll gaps stayed below 89 ms, all timed-out paths emitted new PINGs, while authenticated silence reached 350–487 ms and current RTT remained roughly 4–5 ms at the median. Prior sampled gap maxima reached 256 ms. This is why no fixed deadline enlargement or unmeasured RTT multiplier was applied.
