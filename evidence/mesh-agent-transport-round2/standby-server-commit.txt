Park enrolled fallback connections without replacing the live host (#129)

Accept an optional capability-negotiated standby control request after the
existing nonce proof. Admit its exact certificate through the enrollment
ledger, hold one identity slot (1000 total), release handshake admission,
and cache the server Hello until activation on the same authenticated link.
Revocation and certificate expiry cancel the wait; activation rechecks the
ledger. Greeting writes retain the existing authority fence.

Keeping a second fully active host actor was rejected: it would retire the
mesh terminal and duplicate plugin workers. A cold fallback dial was
rejected because its handshake adds recovery latency. Ordinary greetings
retain their bounded deadline; only an explicitly parked wait outlives it.
No engine change or mandatory protocol field change (D64, D128, D198, D215).
