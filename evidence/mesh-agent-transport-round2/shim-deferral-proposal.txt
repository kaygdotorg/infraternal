D215 round2 #129: proposed additive shared-writer queue contract before policy change.

A valid shared-writer sequenced Input whose unseen suffix exceeds currently available shared-queue space is deferred without changing accepted/written cursors, geometry or ownership segments. Each live peer retains at most one complete bounded frame plus one bounded socket-read suffix; later frames on that peer remain ordered behind it. Acceptance remains atomic when the full unseen suffix fits. The shim stops reading deferred peers, continues servicing other peers and PTY writes, and admits deferred requests fairly. Overlap is recalculated against the durable writer cursor before admission. Peer loss discards only unaccepted deferred data; already accepted input remains queued and the server replays unacknowledged data. Invalid ranges, malformed frames and requests violating ordering remain refusals. The shared accepted queue remains at most 1 MiB; deferred storage belongs only to at most 32 live peers, never to 512 retained identities. Peers without the negotiated SHARED_WRITER capability retain existing capacity-refusal behavior.

Reason: a bounded per-writer server flight alone cannot bound the aggregate surviving queue across retained identities. This applies backpressure without changing frozen frame layouts or choosing a new engine. Real PTY fail-first regression and bounded decoder/order tests will verify it.
