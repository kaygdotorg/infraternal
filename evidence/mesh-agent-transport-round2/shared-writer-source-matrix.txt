#129 optional shared shim writer seam: source findings and test matrix.
Current durable cursors already live in Inputs keyed by writer. The blocker is session.rs duplicate eviction after frame handling, not Inputs::select. Existing framing uses cap bits0/1/2 and tags0x1B SelectWriter,0x1C SnapshotWithFlags; bit3=8/tag0x1D are free in the shim namespace. Local SO_PEERCRED and private socket permissions remain the authority boundary; the host passes only its authenticated durable writer binding.
Design: optional shared mode requires SEQUENCED_INPUT+MULTI_WRITER+SHARED_WRITER negotiated in Attach, then exactly one SelectSharedWriter(nonzero existing writer), before state/input/resize. It never allocates a new durable identity. Ordinary SelectWriter remains valid with or without shared capability and creates fresh ordinary identities. Ordinary peers supersede ordinary peers, shared peers supersede shared peers, the two modes coexist. Disconnected successors must not supersede retained peers.32peer admission refusal must preserve the live ordinary attachment;512retained identities and1MiB shared input queue unchanged.
A parked peer issues no ReadFrom until promotion, so it has no output cursor. Existing InputStateRequest and InputAck are authoritative and bounded; duplicate input is trimmed by the shared accepted cursor and written offsets advance only on actual PTY writes. Actual network priming/cancellation remains separate transport work owned by root. Shared capability is optional and must never become required for fresh ordinary writers after promotion.
Test matrix:
- shim unit frame.rs: fixed little-endian0x1D framing, owned/borrowed agreement, every fragmentation split and short/trailing payload refusal.
- real PTY crates/infraternal/tests/shim.rs: ordinary/shared coexistence, raw echo input replay through both peers yields exactly one payload, equal durable states, shared drop preserves ordinary.
- real PTY: replacement within each mode, fresh ordinary SelectWriter with shared capability advertised/selected remains ordinary; existing caps0 replacement remains unchanged.
- real PTY: missing prerequisite caps, no shared cap, zero/unknown writer, before-Attach/repeated selector refusal; active writer preserved.
- real PTY:32peer full admission refusal preserves active; coalesced malformed shared successor cannot evict valid shared/ordinary peers.
- agent sessions helper tests: refuse old shims before sending new selector, capability intersection, advertised supported helper sends canonical selection.
- existing fuzz target fuzz/fuzz_targets/shim_frame_decode.rs exercises both decoders, roundtrip and fragmented/coalesced stream decoder; requires run after parser addition.
- existing agent_review real-shim regressions: resume, independent writers, geometry and explicit output credit.
- future transport priming: extend parked_fallback_is_cancelled_by_ledger_revocation with actually primed terminal; existing test proves only parked transport cancellation.
No new engine/library. No RTT/scale performance claim from this seam. Root owns final full fast gate and primed transport/recovery measurements.
